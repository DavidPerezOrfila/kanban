# Kanban Board

Minimal Kanban project management board built with Next.js.

## Prerequisites

- Node.js 18+
- npm or bun

## Setup

```bash
cd frontend
npm install
```

## Development

```bash
npm run dev
```

Open http://localhost:3000.

## Unit Tests

```bash
npm run test
```

## E2E Tests

```bash
npx playwright install
npm run test:e2e
```

## Stack

- Next.js (App Router, TypeScript)
- Tailwind CSS v4
- @dnd-kit (drag and drop)
- Vitest + React Testing Library
- Playwright
